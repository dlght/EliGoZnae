🎯 DAILY TRIVIA CHALLENGE - INSTALLATION GUIDE
===============================================

📋 WHAT YOU NEED FIRST:
------------------------
1. Node.js installed on your computer
   Download from: https://nodejs.org (get the LTS version)
   
2. Git installed (for pushing to GitHub later)
   Download from: https://git-scm.com/downloads


🚀 QUICK START (3 METHODS):
----------------------------

METHOD 1: AUTOMATIC (EASIEST!)
-------------------------------
Windows users:
  - Double-click "start.bat"
  - That's it!

Mac/Linux users:
  - Open Terminal in this folder
  - Run: ./start.sh
  - That's it!


METHOD 2: MANUAL (3 COMMANDS)
------------------------------
Open your terminal/command prompt in this folder and run:

  npm install
  npm run dev

Your app opens at: http://localhost:3000


METHOD 3: USING VS CODE
-----------------------
1. Open this folder in VS Code
2. Open Terminal (View → Terminal)
3. Run: npm install
4. Run: npm run dev
5. Your app opens at: http://localhost:3000

🌐 DEPLOY TO WEB:
-----------------

1️⃣ PUSH TO GITHUB:
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/YOUR-USERNAME/trivia-app.git
   git push -u origin main

2️⃣ DEPLOY TO VERCEL (FREE):
   - Go to vercel.com
   - Sign in with GitHub
   - Click "Import Project"
   - Select your repo
   - Click "Deploy"
   - Done in 30 seconds! 🎉

3️⃣ ALTERNATIVE - DEPLOY TO NETLIFY (FREE):
   - Go to netlify.com
   - Drag & drop the "dist" folder after running "npm run build"
   - Done!


💰 ADD GOOGLE ADSENSE:

❓ TROUBLESHOOTING:
-------------------

"npm: command not found"
→ Install Node.js from nodejs.org

"Port 3000 already in use"
→ Stop other apps using port 3000, or edit vite.config.js to change the port

"Dependencies failed to install"
→ Delete node_modules folder and package-lock.json
→ Run: npm install again

"Ads not showing"
→ Wait 24-48 hours after AdSense approval
→ Disable ad blockers
→ Check browser console for errors
